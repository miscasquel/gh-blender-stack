Reference run of the matrix on the development machine. Raw report:
[`2026-11-14-linux.json`](2026-11-14-linux.json).

Command:

```bash
scripts/bench --out benchmarks/results/2026-11-14-linux.json
```

Environment: Blender 5.3.0, Linux 7.3.4 (CachyOS), Python 3.13, AMD Ryzen 7 7700X. The
socket scenarios use `tools/fake_gh`, so `rtt_ms` includes that Python client's
decode, scale, encode and hash. It does not include a Grasshopper solve.

## What this says about the instance-latency report

The old 300–800 ms Stage In report cannot be explained by Blender's side of an
instance-heavy prefix. A 100k-triangle definition placed 13 times costs about
**10 ms** to read and encode, and a repeated apply costs **2.4 ms**. The node
group is reused, not rebuilt.

The remaining candidates are the wire round trip and the Grasshopper side
(Stage In conversion, definition rebuilding, or the definition's own solve).
`rtt_ms` in the fake run is ~109 ms, but that is this machine's Python fake; it
is not a Rhino measurement. A live Rhino run with the same scene is needed to
split `answer` into Stage In and solve. The panel's timing rows and the live
procedure in `benchmarks/README.md` are the measurement path.

The full-request `prefix_ms` reads 0.0 because the connect-time pass had already
memoized the same prefix in that generation; the request still carried the
geometry in full (`encode_ms` and the fake's `received_verts` confirm it).

## 1M note

The 1M case completed without a crash. Peak RSS rose from ~395 MB before the
case to ~609 MB after it, with a 16 MB frame and an 876 ms topology rebuild. The
in-place update is 22.3 ms, so sustained playback does not pay the rebuild cost
after the first frame. This is the recorded budget; it is not a 60 fps claim.

## Caveats

- Numbers are machine-specific; compare runs on the same machine and Blender
  build.
- The fake client is a regression baseline, not a substitute for a live
  Grasshopper solve.
- The 13× case is one 100k definition placed 13 times, not 13 distinct 100k
  definitions. That is the "one geometry instanced 13×" shape from the report.
