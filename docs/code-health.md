## Method and limits

- LOC is physical/code lines, not logical statements; tests, docs, benchmarks and scripts are excluded.
- Largest units are source spans, so nesting is counted in the enclosing unit. C# declarations are found by a brace matcher after comments and strings are blanked.
- Dispatch candidates are literal-driven. A table generated at runtime or a dispatch through an interface is not named here.
- Export candidates are word-scan results. Dynamic callers, reflection, Blender/Grasshopper registration and interface dispatch can hide a use; treat the table as a review queue.
- Test counts are derived from source. Run `scripts/check-all` for measured counts and timings.
