**Decision context** (S9 §D, `spikes/results/s9.txt`):

- A `ModelInstanceDefinition` built from Attributes is valid **only with a
  Name**; named, it previews and bakes with **no document write**. Rhino
  materializes the blocks on first bake and reuses them. `GHStack <hash>` is
  only the fallback name for definitions Blender did not name.
- A nested placement is a `GH_InstanceReference` wrapped with
  `ModelObject.Cast` — the object the Block Definition component takes through
  `Objects`. Stage Out reaches a nested block through `CastTo<GH_InstanceReference>`;
  `CastTo<InstanceReferenceGeometry>` refuses a block-instance ModelObject.
- One definition's rows share a stable reference id for the solve, so Stage Out
  collapses them back into one table entry.
- The wire matrix is row-major with the translation in the fourth column
  (elements 3, 7, 11) — Rhino's layout; Blender transposes. A check that wrote
  it in the last row twice looked like a product bbox limitation.
- Blender's prototype collections are hidden by flag, not view-layer-excluded:
  an excluded collection is not evaluated and Collection Info reads it empty.
