**Decision context** (S9 round 2, `spikes/results/s9.txt` §C):

- No graph-side definition can preview or bake, so definitions go to the open
  document, content-hash named (`GHStack <hash>`), reused across solves and
  never deleted. Without an open document Stage In warns and sends no blocks.
- The wire matrix layout is Rhino's: row-major, translation in the fourth
  column (elements 3, 7, 11). Blender's `instance_transform` reads
  column-major, so the Blender reader/writer transposes.
- Blender's instance references come in three shapes (GeometrySet, Collection,
  Object); the common "Instance on Points" case arrives as a wrapper and is
  hoisted, so it is one definition, not two.
- A prototype collection must be hidden by flag, not view-layer-excluded: an
  excluded collection is not evaluated and Collection Info reads it as empty.

  nested empties are covered headless, not yet live.

  should carry `instances` / `definitions` counts.
