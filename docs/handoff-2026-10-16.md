## 1. Next immediate step: S9 round 2 (live, needs Rhino)

Round 1 answered the attribute question completely (see `s9.txt`): the
`UserDictionary` survives `DuplicateMesh`, `Transform`, `DuplicateGeometry` and
a document bake for mesh, curve, point cloud and SubD.

Round 1's block findings: `ModelObject.Cast` works graph-side, the paired
`InstanceDefinition` survives on the reference, **but** a definition assembled
from `ModelInstanceDefinition.Attributes` is `IsValid=False` with no `Id`; its
reference is invalid, its bounding box invalid (no preview), API bake is a
no-op, and baking one from the canvas raises Rhino's "invalid block instance"
warning (seen live). `Attribs`/`ReferenceID` are not public, so the constructor
path cannot supply identity or content.

Round 2 (deployed) settles it:

```

PYTHONPATH=blender/gh_stack/vendor python3 spikes/s9/driver.py   # 15-minute window
# then drop the "S1 Spike" component (tab "GH Stack S1") on the canvas
```

It reports `definition_cast` (does `ModelInstanceDefinition.Cast` accept the
attributes/objects/object form and yield a valid definition with content?) and
`doc_reference_valid` / `doc_reference_bbox` / `doc_reference_bake` (the
document-definition fallback: added, previewed, baked, then removed from the
document). Then:

- append the results to `spikes/results/s9.txt` and update
  `spikes/s9/README.md` + the CHANGELOG bullet;
- if `Cast` works → Stage In can do graph-side blocks with no document write; if
  not → document definitions (content-hash-named, e.g. `GHStack <hash>`) or
  realized geometry. This decides item 3's GH-side design.

Harness friction seen: the driver's 15-minute window is easy to miss and the

## 3. Next feature: instances as blocks (item 3, not started)

Design agreed in the implementation session, gated by S9 round 2:

- **Wire:** namespaced `idef.<i>.*` section groups (reusing the existing
  writers with a prefix), definition names/ids in the header, plus
  `inst.ref_def` (u32[R]) and `inst.transforms` (f32[R,16], stack-local);
  nested definitions recurse. Add a protocol §5.2 and a fixture.
- **Blender → GH:** stop the silent drop first — `geometry_set_to_sections`
  ignores the instance component today; warn, then read
  `GeometrySet.instances_pointcloud()` / `instance_references()` (5.2 API,
  verified in this session: per-instance `instance_transform` FLOAT4X4 +
  `.reference_index`; references may be GeometrySet/Object/Collection/None).
- **GH → Blender:** definitions as hidden prototype collections; one reference
  point cloud per definition carrying `position`/`rotation`/`scale`, fed into
  `Instance on Points` with the fields **explicitly linked** from Named
  Attribute nodes (verified: the implicit attribute fallback does not fire for
  datablock attributes). Shear cannot be represented → warn; mirrors use
  negative scale.
- **GH Stage Out:** dispatch `GH_InstanceReference`; definition geometry from
  the paired `ModelInstanceDefinition.Objects` when present, else
  `RhinoDoc.InstanceDefinitions.Find(id).GetObjects()`; nested blocks recurse.
- **GH Stage In:** graph-side blocks if round 2's `Cast` works; otherwise the
  document fallback or realized geometry.
- **Tests:** layer B with `fake_gh` (it passes unknown sections through; teach
  it the instance sections), plus the S9/live pass.
