**Decision context** (S9 §C/§D, `spikes/results/s9.txt`):

- Definitions are **named graph-side** `ModelInstanceDefinition`s (the Model
  Block Definition component's route): valid, previewing, baking with **no
  document write** at solve time; Rhino materializes the blocks at bake and
  reuses them. `GHStack <hash>` is only the fallback name.
- **A C# `List<T>` never casts to `List<object>`** (invariance). Wire-parsed
  headers are `List<object>`; anything rebuilt in memory must be read through
  non-generic `IList` or stored in wire shape. This seam caused two separate
  silent block drops; audit it whenever header data crosses a boundary.
- **Blender does not draw instances that reference a datablock while the
  datablock is viewport-hidden.** Prototypes stay hidden, so their geometry
  reaches `Instance on Points` through **Object Info + Join** (copies), never
  Collection Info (references). Probed with A/B/A renders: references drew 0
  pixels, copies 1613.
- The S9 check skips the invalid-reference bake; the dialog that appeared every
  run is gone (owner-confirmed).
